Privacy Policy

This application uses the Google Sheets API with the drive.file scope only. This scope limits access strictly to files this application itself creates or that the user explicitly opens with it - it cannot read, list, or modify any other files in the user's Google Drive.

Data written to the spreadsheet (energy usage figures, invoice data, reimbursement records) originates entirely from the user's own private Home Assistant installation and is written only to the user's own Google Sheet.

No data is shared with, sold to, or accessed by any third party. No analytics or tracking is used on this site or within the application.
